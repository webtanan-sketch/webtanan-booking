# ورود نقش‌محور و رزرو برای افراد خانواده

## هدف

این فاز یک مسیر واحد و قابل اعتماد برای ورود با موبایل، تکمیل اطلاعات بیمار و انتخاب مراجعه‌کننده ایجاد می‌کند. هیچ نوبتی برای کاربر مهمان قفل نمی‌شود.

## جریان ورود

1. کاربر وارد صفحه «ورود و ثبت‌نام» می‌شود.
2. شماره موبایل را وارد و کد یک‌بارمصرف را تایید می‌کند.
3. حساب موجود با کلیدهای موبایل وردپرس پیدا می‌شود؛ فقط در صورت نبود حساب، نقش `webtanan_patient` ساخته می‌شود.
4. نقش پزشک یا منشی به پیشخوان پزشک و نقش بیمار به پنل بیمار هدایت می‌شود.
5. بیمار جدید پیش از ورود به پنل، نام، نام خانوادگی و کد ملی معتبر را تکمیل می‌کند.

شماره ورود پزشک در فرم مدیریت پزشک و متاباکس CPT ذخیره می‌شود:

`webtanan_mobile`

یک شماره موبایل نمی‌تواند به دو حساب متفاوت متصل شود.

## REST

- `GET /saas/v1/auth/context`
- `POST /saas/v1/auth/send-otp`
- `POST /saas/v1/auth/verify-otp`
- `POST /saas/v1/auth/complete-profile`
- `GET|POST /saas/v1/patient-panel/profile`
- `GET|POST /saas/v1/patient-panel/dependents`
- `DELETE /saas/v1/patient-panel/dependents/{id}`

## رزرو امن

ترتیب رزرو عمومی:

1. انتخاب روز و ساعت آزاد.
2. ورود OTP در همان پنجره در صورت مهمان بودن.
3. تکمیل اطلاعات هویتی در صورت ناقص بودن حساب.
4. انتخاب «خودم» یا فرد ذخیره‌شده.
5. ایجاد قفل نوبت.
6. نمایش شمارش معکوس و مرحله پرداخت.

endpoint قفل فقط برای کاربر واردشده قابل استفاده است. `dependent_id` توسط سرور با user meta همان حساب تطبیق داده می‌شود و اطلاعات هویتی مراجعه‌کننده از کلاینت پذیرفته نمی‌شود.

اطلاعات پروفایل و فهرست افراد در `wp_localize_script` یا HTML اولیه صفحات عمومی قرار نمی‌گیرد. این داده‌ها فقط پس از احراز هویت از REST دریافت می‌شوند تا کش صفحه باعث افشای اطلاعات شخصی نشود.

## افراد من

افراد وابسته در user meta زیر نگهداری می‌شوند:

`webtanan_patient_dependents`

هر مورد دارای شناسه UUID، نام، نام خانوادگی، کد ملی، موبایل اختیاری و نسبت است. سقف فعلی ۲۰ فرد برای هر حساب است.

## پذیرش UI

- مهمان پس از انتخاب ساعت، فرم ورود را داخل همان رزرو می‌بیند.
- پیش از ورود یا انتخاب مراجعه‌کننده، هیچ قفل زمانی ایجاد نمی‌شود.
- زمان قفل از `locked_until_timestamp` واقعی سرور محاسبه می‌شود.
- کارت پزشک فقط اطلاعات پزشک، نوبت آزاد و نشان تایید آبی دارد.
- صفحه آرشیو فقط فیلترهای کاربردی نام، تخصص و نوبت آزاد را نشان می‌دهد.
- پنل بیمار هدر تکراری ندارد و بخش «افراد من» از منوی نقش‌محور قابل دسترسی است.
- صفحات قدیمی داشبورد که روی قالب بدون هدر `template-saas-canvas.php` بوده‌اند، در admin به `template-contained.php` مهاجرت می‌کنند تا فقط هدر اصلی سایت نمایش داده شود.
