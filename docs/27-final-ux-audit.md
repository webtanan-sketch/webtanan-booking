# ممیزی نهایی تجربه کاربری - نسخه 1.4.4

## دامنه بررسی

- ورود OTP و تکمیل حساب
- جستجو، کارت و پروفایل پزشک
- انتخاب روز و ساعت، نگهداری موقت نوبت، پرداخت و رسید
- پنل بیمار، افراد من، پزشکان منتخب، کیف پول، پرونده و راهنما
- پیشخوان پزشک و منشی، نوبت‌ها، پرونده، برنامه هفتگی، روزهای خاص و تسویه
- مودال‌ها، خطاها، حالت خالی، موبایل، صفحه‌کلید و متن‌های قابل مشاهده
- هماهنگی requestهای فرانت با routeهای REST

## اصلاحات تاییدشده با بررسی کد

1. همه 48 مسیر فراخوانی‌شده از فرانت دارای route متناظر هستند.
2. خطای شبکه خام مرورگر به پیام فارسی تبدیل شده است.
3. مودال‌های رزرو، تایید، نوبت حضوری و تکمیل پرداخت focus trap، Escape و بازگشت فوکوس دارند.
4. منوی موبایل بیمار و پزشک با Escape، backdrop و انتخاب آیتم بسته می‌شود.
5. وضعیت‌ها و روش‌های پرداخت قبل از نمایش به متن فارسی نگاشت می‌شوند.
6. `lock_token` و شناسه‌های داخلی در متن قابل مشاهده چاپ نمی‌شوند.
7. روز بدون ساعت آزاد، مسیر مستقیم به اولین نوبت آزاد دارد.
8. پرداخت ناقص از پنل بیمار دوباره فاکتور و انتخاب کیف پول/درگاه را نمایش می‌دهد.
9. پزشک می‌تواند خدمات، مدارک، FAQ، تصویر و گالری پروفایل عمومی را ویرایش کند.
10. برنامه هفتگی و روزهای خاص قابل افزودن و حذف هستند و افزودن بازه تکراری، رکورد قبلی را به‌روزرسانی می‌کند.
11. تب‌های پروفایل عمومی فقط وقتی مقصد واقعی دارند نمایش داده می‌شوند.
12. کد OTP در پاسخ REST حالت debug افشا نمی‌شود.

## تست‌های قابل انجام در مخزن

- PHP syntax lint برای همه فایل‌های PHP قالب و افزونه
- JavaScript syntax check برای فایل‌های JS
- تطبیق استاتیک routeهای فرانت و REST
- اسکن debug output و متن‌های داخلی
- بررسی ساختار CSS، hidden state و responsive media queryها

## مواردی که فقط روی سایت نصب‌شده قابل تایید قطعی هستند

- تحویل واقعی پیامک IPPanel با API Key، شماره فرستنده و pattern تاییدشده
- پرداخت واقعی و callback آقای پرداخت
- نمایش در مرورگر در 390، 768، 1366 و 1920 پیکسل با قالب، Elementor و افزونه کش واقعی سایت
- تست همزمانی دو کاربر روی یک ساعت و replay callback در دیتابیس MySQL مقصد
- خروجی sitemap و canonical نهایی Rank Math پس از بازسازی پیوندهای یکتا

بدون وردپرس نصب‌شده، credential سرویس‌ها و دیتابیس مقصد، ادعای تایید صددرصد این پنج مورد فنی صحیح نیست. پیش از انتشار عمومی باید smoke test عملیاتی مطابق این فهرست اجرا شود.
